# Customer Shopping Data Analysis

## Project Overview

This project performs Exploratory Data Analysis(EDA) and Business Intelligence analysis on a customer shopping dataset. The goal is to understand customer behaviour, purchasing patterns, revenue trneds, and business insights using Python, SQL, and dashboard visualization.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- SQLite
- Microsoft Excel
- Google Colab

## Tasks Performed
- Data Loading and Exploration
- Descriptive
- Univariate Analysis
- Multivariate Analysis
- Correlation Analysis
- SQL Business Queries
- Dashboard Creation

## Key Insights
- Customers belong to a wide range of age groups.
- Female customers make more purchases than male customers.
- Most purchases are low to moderate in value.
- Age has little impact on spending behaviour.
- Quantity and price show a moderate positive relationship.
